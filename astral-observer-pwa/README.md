# Astral Observer

Astral Observer is a complete astronomy-focused PWA starter built with **React + Vite + Tailwind CSS**. It uses browser geolocation to show observation conditions, visible constellations, a live sky map, upcoming celestial events, and a dedicated astrological transits section.

## What is included

- Browser geolocation with graceful fallback to Greenwich Observatory
- Real-time weather and visibility scoring using Open-Meteo
- Day/night detection and sunset/sunrise context
- Visible constellations for tonight and tomorrow night
- Interactive sky map using VirtualSky
- Astronomy agenda with eclipses, meteor showers, conjunctions, and moon phases
- Astrological transits calculated locally from planetary longitudes
- PWA install prompt, manifest, service worker, and offline caching
- Responsive dark-only UI with a futuristic dashboard layout

## Free integrations used

### Core integrations

- **Open-Meteo** — free/open weather data, no API key required for the core forecast flow
- **Astronomy Engine** — MIT-licensed astronomy calculations running locally in the browser
- **VirtualSky** — open-source interactive planetarium embedded from local static assets
- **Bundled datasets** — local fallback/recurring data for meteor shower windows and constellation centers

### Optional integration

- **OpenCage** — optional free-trial reverse geocoding for nicer human-readable place labels
  - If not configured, the app automatically falls back to latitude/longitude labels.

## Fallback strategy

The app does not depend on any paid astronomy APIs.

- **Weather / visibility** → Open-Meteo live API
- **Constellation visibility** → local astronomy math + bundled constellation center dataset
- **Astronomy agenda** → local calculations for moon phases, eclipses, conjunctions + bundled meteor shower windows
- **Astrological transits** → fully local fallback (planetary ecliptic longitudes, signs, and aspects)
- **Location naming** → optional OpenCage key; otherwise raw coordinates
- **Offline mode** → service worker cache + localStorage snapshot of the last successful dashboard payload

## Setup

### 1) Install dependencies

```bash
npm install
```

### 2) Optional: add API keys

Copy the env example:

```bash
cp .env.example .env
```

Then edit `.env` if you want reverse geocoded place names:

```env
VITE_OPENCAGE_API_KEY=your_opencage_key_here
```

### 3) Start development

```bash
npm run dev
```

### 4) Build and preview production

```bash
npm run build
npm run preview
```

## API key placement

Place Vite environment variables in a project-root `.env` file.

Example:

```env
VITE_OPENCAGE_API_KEY=your_opencage_key_here
```

Inside the app, the key is read from `src/config/env.js` using `import.meta.env`.

## Which keys are actually required?

None for the core experience.

The astronomy dashboard, weather conditions, constellation visibility, live sky map, and astrological transits all work **without any API keys**.

The only optional key in this starter is:

- `VITE_OPENCAGE_API_KEY` — enables a nicer reverse-geocoded place label

## Notes on PWA behavior

- The web manifest is configured in `vite.config.js` and generated at build time.
- The service worker is generated by `vite-plugin-pwa` during build.
- Runtime caching is configured for Open-Meteo and optional OpenCage requests.
- The app also stores the last successful dashboard payload in `localStorage` so it can surface cached content when live refresh fails.

## Deploy

This project is ready to deploy to any static host that supports HTTPS, such as:

- Vercel
- Netlify
- Cloudflare Pages
- GitHub Pages (with a small base-path adjustment if needed)

For the best install and geolocation behavior, deploy over **HTTPS**.

## Implementation notes

### Weather and observation score

The current observation score is a simple weighted model based on:

- cloud cover
- visibility
- wind
- whether it is day or night

You can refine the scoring logic in `src/utils/observation.js`.

### Constellations

The constellation lists are estimated from bundled representative RA/Dec positions and converted to apparent horizon altitude for the user’s coordinates.

### Astrological transits

No reliable universal free transit API was used here. Instead, the project computes:

- geocentric planetary longitudes
- zodiac signs
- retrograde direction
- major aspects

That keeps the feature free, deterministic, and deployable without vendor lock-in.
